INVENTORY MANAGEMENT SYSTEM

Files:
- Main.java
- MainFrame.java
- Inventory.java
- Product.java
- Supplier.java

HOW TO RUN (Windows Command Prompt):
1. Open the InventoryManagementSystem folder.
2. Click the folder address bar, type cmd, and press Enter.
3. Compile:
   javac *.java
4. Run:
   java Main

Requirements: Java JDK installed (not just JRE).

The project was compiled successfully with javac.
